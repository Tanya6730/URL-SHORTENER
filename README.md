🔗 URL Shortener

A full-stack URL shortening application built with the MERN stack.

The application allows users to enter a long URL and generate a shorter, shareable link. It also provides QR code generation, copying, and downloading functionality.

---

✨ Features

- 🔗 Shorten long URLs into compact links
- ⚡ Generate unique short IDs
- 🔄 Redirect short URLs to their original URLs
- 📋 Copy shortened URLs with one click
- 📱 Generate QR codes for shortened URLs
- ⬇️ Download generated QR codes
- 🗄️ Store URL data using MongoDB
- 🌐 REST API built with Express.js
- 🔌 React frontend connected to the backend using Axios
- 🔐 Environment variables for configuration
